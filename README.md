                                                 Pizza Factory – Unity Gameplay System

A Unity game prototype where the player creates pizzas by selecting toppings using raycasting interaction, while the pizza is generated through a step-by-step production system optimized with advanced object pooling.

         Gameplay

The player interacts with toppings using raycasting and builds a pizza through multiple stages:

Select toppings using mouse / touch interaction

Toppings are detected using Raycast system

Pizza moves through different preparation stages

Selected toppings are applied at each stage

Objects are spawned efficiently using Advanced Object Pooling

        Systems Implemented

Raycast-based topping selection

Advanced Object Pool Manager

Pizza Spawn Manager

UI Manager for topping selection

Step-by-step pizza production pipeline

Automatic object disable system

Animation handling system
